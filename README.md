---

## Overview

The **Autism Prediction System** is a machine-learning-based web API built with
**FastAPI** that predicts the likelihood of autistic traits based on the
Q-Chat-10 behavioural screening questionnaire and demographic information.

The project is structured for production readiness with proper code organisation,
type hints, comprehensive testing, Docker support, and thorough documentation.

## Quick Start

### Prerequisites

* Python 3.12+
* `pip` or a virtual-environment manager

### 1. Clone & install

```bash
git clone https://github.com/kushagrabatra/autism-prediction-.git
cd autism-prediction-/ml_testing

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Train the model (optional — pre-trained artifacts are included)

```bash
python train_model.py data/"Toddler Autism dataset July 2018.csv"
```

### 3. Run the server

```bash
uvicorn main:app --reload
```

Open your browser at http://localhost:8000/frontend/index.html for the web UI
or http://localhost:8000/docs for the interactive API documentation.

## API Reference

Interactive documentation is available at `/docs` (Swagger UI) and `/redoc`.

### `GET /health`

Returns a simple liveness check.

**Response `200`:**
```json
{ "status": "ok", "message": "Autism Prediction API is running" }
```

---

### `POST /ml/predict`

Run an ASD screening prediction.

**Request body:**
```json
{
  "features": {
    "A1": 0, "A2": 0, "A3": 0, "A4": 0, "A5": 0,
    "A6": 0, "A7": 0, "A8": 0, "A9": 0, "A10": 0,
    "Age_Mons": 36,
    "Qchat-10-Score": 6,
    "Sex": "m",
    "Ethnicity": "White European",
    "Jaundice": "no",
    "Family_mem_with_ASD": "no",
    "Who completed the test": "family member"
  }
}
```

**Response `200`:**
```json
{ "prediction": "No", "probability": 0.97 }
```

**Validation rules:**

| Field | Valid values |
|---|---|
| `A1`-`A10` | `0` or `1` |
| `Age_Mons` | `0`-`300` (months) |
| `Qchat-10-Score` | `0`-`10` |
| `Sex` | `"m"`, `"f"` |
| `Jaundice` | `"yes"`, `"no"` |
| `Family_mem_with_ASD` | `"yes"`, `"no"` |
| `Who completed the test` | `"family member"`, `"healthcare professional"`, `"self"`, `"others"` |

**cURL example:**
```bash
curl -X POST http://localhost:8000/ml/predict \
  -H "Content-Type: application/json" \
  -d '{"features":{"A1":0,"A2":0,"A3":0,"A4":0,"A5":0,"A6":0,"A7":0,"A8":0,"A9":0,"A10":0,"Age_Mons":36,"Qchat-10-Score":6,"Sex":"m","Ethnicity":"White European","Jaundice":"no","Family_mem_with_ASD":"no","Who completed the test":"family member"}}'
```

## Machine Learning Model

| Property | Value |
|---|---|
| Algorithm | Random Forest (best of 4 candidates evaluated) |
| Dataset | Q-Chat-10 Toddler Autism Screening (July 2018) |
| Features | 17 (10 binary screening items + 7 demographic) |
| Target | `Class/ASD Traits` (`"Yes"` / `"No"`) |
| F1 Score | 1.00 (on held-out 20% test split) |
| Accuracy | 100% (on held-out 20% test split) |

> **Note:** Perfect scores on this dataset likely reflect an easy-to-separate dataset
> rather than universal generalisability. Do not interpret high accuracy as clinical validity.
